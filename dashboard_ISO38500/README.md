# Dashboard ISO/IEC 38500:2024

Dashboard estratégico de métricas de Gobierno de TI, Gobierno de Datos e IA, basado en la ISO/IEC 38500:2024.

Hecho con Python, Streamlit, Pandas, Matplotlib y Seaborn. Los datos se leen de un Excel en Google Drive.

## Secciones

- Resumen
- ISO 38500
- Gobierno de Datos
- Gobierno de IA
- Operación TI
- BSC
- Portafolio
- Innovación
- Riesgos
- Arquitectura
- Contexto
- Calidad de datos

## Instalación

```
pip install -r requirements.txt
```

## Ejecución

```
streamlit run app.py
```

En Windows también se puede abrir con doble clic en `iniciar.bat`.
